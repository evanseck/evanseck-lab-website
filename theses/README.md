# Theses and dissertations

Put PDFs of theses here to make them readable on the website (Past members).

Name the PDF exactly like the person's file in `content/people/alumni/`, ending in `.pdf`:

| Person's file | PDF to upload here |
|---|---|
| `content/people/alumni/witte-anna.md` | `theses/witte-anna.pdf` |
| `content/people/alumni/makowski-joseph.md` | `theses/makowski-joseph.pdf` |

The title of their thesis on the site then links to the PDF automatically.
Only post theses the author has agreed to share. Keep each file under 25 MB (GitHub's limit for
uploads through the website).

Dissertations in Duquesne's online archive are linked automatically and don't need a PDF here.
